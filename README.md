# sysshop
a minecraft mod to realize barter (have system barter shop,op lvl2 can manager system shop at page "manager your shop"), write by GPT-6 Luna
## How to use
'/sysshop open' to open shop menu
'/sysshop create' to create new shop
'/sysshop manager' to manager your shop
'/sysshop shop' same as '/sysshop open'

# 以物易物
由GPT-6 Luna写的模组，旨在实现游戏内以物易物的功能，若在服务器中使用则有系统商店功能，2级以上管理员可在“管理你的商店”菜单编辑系统商店，由GPT-6 Luna编译
## 如何使用
'/sysshop open' 打开商店菜单
'/sysshop create' 创建新商店
'/sysshop manager' 管理你的商店
'/sysshop shop' 与 '/sysshop open' 相同
